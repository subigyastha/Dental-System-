Which approach fits this clinic?

Recommended first

A. Daily list + short log panel

See everyone due. Open Log result, choose the response and save. Keep your place.

Easy to scan, choose and revisit. Fits interruptions at reception.

B. One client at a time

Start follow-ups → one client → log → next client.

Good for a dedicated calling session. Less flexible when staff are interrupted; add later if needed.

C. Status board

Columns for waiting, contacted and completed.

Dates and results do not fit one simple status. Dragging adds work and can hide an unanswered call. Avoid for the first version.

The shortest useful flow

1

Know who to contact

Today opens by default. Phone, reason, due time, return-visit context and last result are visible.

2

Make contact, then log

Open Log result. Choose the response. Add a note only if useful. Channel and time remain available without dominating the form.

3

Save and keep working

Return to the same place. No answer stays open. Contact later asks for the date staff choose. No automatic next reminder.

Small form, accurate records
  • “Last spoke” and “last attempt” are distinct. Staff notes and client feedback are labelled separately.
  • Provider review remains visible and follows existing permissions. A flag is not proof that a provider was notified.
  • Use one main row action; history opens from the client or log panel. Reschedule edits the same task.
  • Keep date-only reminders and later-today times readable; overdue labels use the clinic timezone.
  • Client profile: identity, key clinical details and next follow-up remain visible; full histories may use tabs.
